===================== PH17 DEFECT + FIX RECORD (2026-11-20) =====================
DEFECT (VLM pass 1, both themes): the DUMBBELSS spanning banner's four rotated
text lines rendered BELOW the amber column (anchor construction bug: the four
<text transform="rotate(-90 400 616)" textAnchor="end" y=576..615> lines mapped
all anchors to y=612 with text extending downward past the column rect
y-bottom 620, spilling over the spine bottom edge into the trap band; the
column itself rendered mostly empty).
ROOT CAUSE OF THE AUDIT GAP (documented for the pipeline): getBBox() measures
the element's LOCAL pre-transform box — it does NOT apply the element's own
transform attribute. The rotated lines' pre-transform boxes sit stacked 18
units apart (no >1px overlap pre-transform), so the geometry audit reported 0
overlaps on the DEFECTIVE build; after the fix the same audit reports 7
"overlaps" that are FALSE POSITIVES (the pre-transform boxes of four
horizontally-laid-out strings). Rotated-text visuals must be verified
visually (VLM/crops), not by the getBBox audit.
FIX (src/components/kyp/usmle/visuals/pharm-p17.tsx): the four lines
re-anchored rotate(-90 H 608) x=H y=608 textAnchor="start" at H=344/366/384/402
— each line now starts at the column bottom (y 608) and reads bottom-to-top
inside the column (computed AABBs x 339-345/356-371/378-390/394-406, all within
the column rect x 314-426 y 104-620, pairwise disjoint).
